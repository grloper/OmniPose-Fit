# PushTrack - Android Push-Up Counter

This repository contains the source code for PushTrack, an Android application that uses your device's camera and computer vision to count push-ups in real-time.

## 🏗️ Project Status

This project is currently under development. The initial setup is complete, and the core features are being implemented.

## 🛠️ How to Build and Run

### Prerequisites

*   Android Studio (latest version recommended)
*   An Android device or emulator with camera access

### Steps

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    ```

2.  **Open in Android Studio:**
    *   Open Android Studio.
    *   Select "Open an Existing Project".
    *   Navigate to the cloned repository folder and open it.

3.  **Sync Gradle:**
    *   Android Studio should automatically sync the project with Gradle. If not, click the "Sync Project with Gradle Files" button in the toolbar.

4.  **Run the application:**
    *   Select a run configuration (usually `app`).
    *   Choose a target device (emulator or a physical device connected via USB).
    *   Click the "Run" button (green play icon).

The application will be installed and launched on your selected device. You will need to grant camera permissions for the app to function correctly.
